# Dimensioni per la responsività

| Dispositivo    | Dimensione (px) |
| -------------- | --------------- |
| Mobile piccolo | 320px           |
| Mobile medio   | 375px           |
| Mobile grande  | 425px           |
| Tablet         | 768px           |
| Laptop         | 1024px          |
| Laptop grande  | 1440px          |
| 4K             | 2560px          |

Queste dimensioni rappresentano i breakpoint comuni utilizzati in chrome.
È importante testare il design soprattutto su queste dimensioni di schermo per garantire un'esperienza utente ottimale su tutti i dispositivi.
